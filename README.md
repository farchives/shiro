# Shiro

A dog care reference site for Shiro — a doodle — built for sitters and guests who need a quick, reliable guide.

## What's on the site

- **Meet** — breed, age, personality snapshot
- **Schedule** — her daily routine
- **Feeding** — what and when she eats
- **Grooming** — coat care basics
- **Play** — how to tire her out (training, fetch, enrichment toys, brain games)
- **Commands** — the cues she knows
- **Bone holder** — independent activity setup
- **Leaving her alone** — pre-departure checklist
- **Emergency** — vet and ICE contacts
- **Gallery** — photos

## Stack

- [Astro](https://astro.build) — static site framework
- [React](https://react.dev) + [Framer Motion](https://www.framer.com/motion/) — interactive components and animations
- [Tailwind CSS](https://tailwindcss.com) — styling

## Local dev

```bash
npm install
npm run dev
```

Runs at `http://localhost:4321`.

## Build

```bash
npm run build
npm run preview
```
